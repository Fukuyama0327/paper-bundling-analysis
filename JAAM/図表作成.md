# JAAM和文論文の図表

`make_jaam_figures.py` は、論文で使用する図10種類（図7は全体図と拡大図の2枚）を元データから一括作成します。
既存の英語版 `figures/` と `paper/20261022_DL/figures/` は更新しません。

```bash
MPLCONFIGDIR=/private/tmp/jaam-mpl python3 JAAM/make_jaam_figures.py
```

出力先は `JAAM/figures/` です。各図をPNG（400 dpi）とPDFで保存し、
最適化結果の表データもCSVとして保存します。WordではPNGを**幅7.6 cm**で配置します。
図自体をこの幅で描いているため、文字は配置時に縮小されず、およそ8～9 ptです。
キャプションはWord本文側で日本語として付けます。

入力は `data/processed/` の対象橋梁・点検・最適化結果・橋梁割当と、
`outputs/` の期待契約件数の計算結果です。図表作成時に最適化や劣化推定は再実行しません。
元図の配色、線種、表示系列、注記、凡例位置を基本として、軸名と凡例を日本語にしています。
図8・10の地図は元図と同様に、橋梁の割当に基づく最近接橋梁の色分け面と
橋梁点を示します。色分け面は候補を見やすくするためのVoronoi表現であり、
実際の管理区域境界ではありません。背景の線は6市町の行政界です。

実行環境には `numpy`, `pandas`, `matplotlib` と日本語フォントが必要です。

図を更新した後にWord草稿を再生成する場合は、`python-docx` を使って
次を実行します。草稿の既存ファイルを上書きします。

```bash
python3 JAAM/build_jaam_draft.py
```
